Tarea 1: Empezando con Express y Node.js

Durante el curso haremos variantes de parte de la Tienda Prado, la parte de submenu Impresiones

Empezaremos haciendo una Multiple Page Application, en las que todas las páginas estén generadas desde el servidor consultando una Base de Datos. Queda para mas adelante versiones con modo distinto de generación del HTML: una Single Page, y otra Server Side Rendering.

Para esta primera versión usaremos el framework Express, con Nunjucks como motor de plantillas. Seguiremos How to Set Up Nunjucks with ExpressJS y la IA para poner en marcha el servidor.

Lo primero será asegurarnos de tener instalada al menos la versión 23 de Node.js, ya que vamos a usar alguna de sus posibilidades:   watch mode,   support for .env variables   y   TypeScript nativo

Node viene asociado con npm, un gestor de dependiencias, similar al pip de python. Alternativamente podemos usar pnpm.

Usaremos el sistema módulos ES6, (ECMAScript modules en Node.Js). Es decir usaremos import en lugar de require().

Empezando con la aplicación
Muy recondable usar git, y luego: 
$ mkdir SSBW; cd SSBW
$ touch Makefile              // para las ordenes repetitivas
$ touch .env                  // para variables de entorno
$ touch index.ts              // el servidor (typescript)

// instalamos dependencias
$ npm init                    // (poner type="module")
$ npm i express nunjucks      // framework, plantillas

// y ahora las de desarrollo

// reinicio automático de las plantillas cuando se cambian
$ npm i -D chokidar

// tipos (para vscode)           
$ npm i -D @types/express @types/nunjucks @types/node
nujucks es una libreía de templating compatible con jinja, twig, o los templates de Django.

y en packaje.json 
...,
"scripts": {
	"dev": "node --watch --env-file=.env index.ts"
},	
...
